# Realm Guard / Torchbearer v1.11.0

## M10A — Realm Guard Strict · STABLE / GOLD

v1.11.0 promotes the verified v1.11.0-qa.11 codebase without functional gameplay/runtime changes.

### Rules Profiles
- **Realm Guard — Legacy Mixed** remains the default compatibility profile.
- **Realm Guard — Strict** is now a supported explicit profile (profile v10).
- GMs can preview conversion impact and switch Legacy Mixed ↔ Strict reversibly from Rules Profile Management.
- Profile switching preserves existing campaign data instead of destructively cleaning or converting it.

### Strict Realm Guard
The stable Strict profile includes the verified M10A rules ownership for:
- rated Wises, I Am Wise and Wise Teamwork
- MG1E-based Strict Trait semantics
- Realm Guard Strict Conditions and Recovery
- LOOSE inventory semantics and Strict Conflict tool authority
- Session / Checks / End Session
- Circles / Enmity integration through CORE M8
- Pass/Fail advancement and Beginner's Luck
- CORE M9 Strict Character Creation
- Realm Guard v1.6 Scale of Might guidance
- activation-aware Manual and Strict Rules Reference

### Data safety
- No automatic rating is assigned to preserved old Wises.
- Existing Levels/Talents are preserved when Strict disables them mechanically.
- Fresh/Afraid and structured inventory metadata are preserved for reversible profile switching.
- Strict-created data remains intact after rollback to Legacy Mixed.

### Other
- Includes the system-owned Quick NPC Provider API introduced during qa.10.
