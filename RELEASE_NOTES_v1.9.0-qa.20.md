# Realm Guard / Torchbearer v1.9.0-qa.20 — Character Sub-Navigation

Visual / UX-only Character sheet restructuring.

- Adds a secondary menu inside CHARACTER:
  - Overview
  - Background
  - Relationships
  - Notes
- The secondary menu only exists while CHARACTER is active.
- Switching to Skills or Inventory & Gear hides the Character menu with the Character page.
- Returning to CHARACTER remembers the last Character subsection used during the sheet session.
- Existing data fields are unchanged.
- Overview contains Belief / Goal / Instinct, Wises, Traits, Level & Talents.
- Background contains Biography, Lineage / House and House Insignia.
- Relationships contains the current legacy Parents / Senior Artisan / Mentor / Friend / Enemy fields.
- Notes contains Character Notes.
- No M8 Social Network data migration or live Circles behavior is introduced yet.
