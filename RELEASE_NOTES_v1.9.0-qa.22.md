# Realm Guard / Torchbearer v1.9.0-qa.22 — NPC + Item Parchment Harmony

Visual-only continuation of the sheet redesign.

## NPC
- NPC sheet now uses the same framed parchment background as the Ranger Character sheet.
- NPC header remains a dark forest/brass identity anchor.
- Ability cards, Quick Skills, Conditions, Traits, Wises, Talents, Gear and GM Notes are integrated into parchment surfaces.
- Quick Skill cards use paper surfaces with clear rating emphasis.
- Notes use light writing-paper fields.
- Existing NPC actions, drag/drop, rolls and GM controls are unchanged.

## Items
- Item windows now use the same framed parchment background.
- Realm Guard brand becomes a compact forest/brass heading.
- Name, numbers, selects and descriptions use paper writing fields.
- Gear, Token of Power and Talent editors use parchment cards with dark forest section headers where appropriate.
- Existing Item data and behavior are unchanged.

No rules, Actor/Item schema, Recruitment, CORE authority, M7 behavior or M8 Social Network behavior changes.
