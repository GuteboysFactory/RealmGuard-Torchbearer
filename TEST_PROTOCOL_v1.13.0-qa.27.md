# Testprotokoll 1.13.0-qa.27

## Omfattning
Återställning till QA25 + endast godkända Nature och Creed i PC Overview. QA26 är ersatt och ska inte användas. Ingen ny TB2E-beta aktiveras. QA25:s wizard och regler är återställda.

## Före installation
Om QA26-profilen Torchbearer 2E Playtest Beta är aktiv: byt tillbaka till den profil du använde före QA26 via Profile Management innan uppdateringen. Välj Legacy Mixed om det var din tidigare profil.

## A. Installation
Uppdatera via vanliga QA-länken och ladda om världen. Förväntat: version 1.13.0-qa.27. Den separata QA26 Creator Guide och Adventure/Camp/Town-panelen finns inte längre.

## B. Overview
Öppna en befintlig PC. Förväntat: Nature, Belief, Goal, Instinct, Creed i samma stil som det godkända QA26-utseendet. Skriv i Nature och Creed, lämna fältet, stäng bladet och ladda om. Förväntat: texterna finns kvar. Nature-värdet för tärningsslag är oförändrat.

## C. Befintlig wizard
Öppna den vanliga karaktärswizarden och avbryt utan att skapa någon. Förväntat: den befintliga QA25-wizarden öppnas, inte QA26:s förenklade guide.

Rapportera A/B/C PASS eller konkret avvikelse. Tidigare godkända regeltester behöver inte göras om för detta paket.
