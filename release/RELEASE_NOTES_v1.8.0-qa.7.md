# v1.8.0-qa.7 — Conflict Parchment UI Prototype

A visual-only Conflict/roll UI prototype inspired by the warm parchment reference direction approved during QA.

## Included
- New reusable Conflict parchment background asset.
- Conflict Window parchment presentation with clearer GM/Ranger identity.
- Higher-contrast Goals and Disposition cards.
- Stronger Current Action visual hierarchy.
- Parchment styling for planning, guidance, Maneuver, Compromise and history surfaces.
- Matching parchment presentation for Conflict Action roll dialogs.
- Matching background treatment for Conflict setup, Goal, Starting Disposition, Disarm and custom Conflict Tool dialogs.
- Responsive rules retained.

## Deliberately unchanged
- M6 resolution authority.
- M6 state-transition authority.
- Conflict rules and interaction matrix.
- Hidden plans and socket workflow.
- Exchange-scoped Weapon / Tool behavior.
- Maneuver effects and Disarm duration.
- Advancement, Learning, Nature, Fate/Persona and compromise rules.

This build is intended to answer one question in live play: does the parchment direction improve clarity and feel without harming usability?
