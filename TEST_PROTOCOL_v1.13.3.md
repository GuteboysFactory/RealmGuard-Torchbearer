# 1.13.3 — Foundry acceptance checks

Use a backed-up test world with Legacy Mixed selected. Check that Foundry reports system version 1.13.3. No actor/inventory conversion is required.

1. Open a player character. Check the larger portrait, hover/focus editing icons, compact abilities, Custom Roll and Conditions. Collapse/expand the header; switch Character, Skills and Inventory. Scroll and revisit a tab; its position should be retained while the sheet remains open. Repeat in a smaller resized window.
2. In Skills, verify trained and untrained cards have Roll beside Edit and no Quick Roll or external Versus checkbox. Edit Pass/Fail and learning attempts, exercise Cancel, and ensure valid saved corrections appear. Check an untrained Skill whose Nature is taxed: learning target must use maximum Nature. Confirm both success and failure add an attempt when counting learning, and the Skill opens at 2 after the required attempts without advancing Will/Health.
3. Open Roll, select Versus, search/select a visible opponent and choose an offered opposition. Complete the roll and check chat. Repeat with Beginner’s Luck; then use Standard again. Verify cancellation does not roll or spend resources, and choosing an opponent does not change scene token targets.
4. In Inventory check Human/Elf/Dwarf/Hobbit male and female figures. Blank ancestry must display Human. Only Male/Female is selected in this area; ancestry is read from character data. Hover/focus points, open occupied/empty slots, search gear, equip/take off and move gear between zones/containers/Unassigned. A two-handed weapon must still block the other hand. Check that existing contents/quantities remain intact. Search for an equipped item too.
5. As GM, right-click blank canvas and a token on the token layer. Try opening Actor/Conditions, Custom Roll, targeting, Conflict, End Session, ping and placing an existing NPC token. Confirm token placement does not create another Actor. Exercise right-drag pan, Shift-right-click, Foundry token controls, Escape and outside-click dismissal. Repeat as a player: the GM menu must not appear.
6. Recheck Conflict with multiple players: one shared player Disposition roll, distribution, manual Skill choice, equipment/card selection, hidden plans, explicit flips and Back. Recheck End Session saved participants and rewards. Use separate GM/player browsers for this integration pass.
7. Switch to Strict, MG1E, MG2E or TB2E in a separate test world and reload. The Legacy-only layout, figures, menus and rule adjustment must not appear. Startup performance must remain comparable to the accepted baseline.

Completed automated evidence is in LEGACY_WORKSPACE_REVIEW.md. Those tests are actual Chromium DOM tests with production modules/templates/styles and controlled Foundry fixtures; they do not replace the live-server acceptance above.
