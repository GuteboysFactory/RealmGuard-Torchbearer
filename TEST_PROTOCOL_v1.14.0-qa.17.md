# Foundry test protocol for 1.14.0-qa.17

Use Foundry 13.351 in a test world.

1. Open a Legacy Mixed character in **Compact**. Check the tighter spacing around Will, Health, Resources and Circles. Verify the header on Character, Skills and Inventory & Gear.
2. Open **Background** and confirm that Concept retains its text and is editable. With Turn Manager enabled, confirm that Compact omits the Players' Turn row and Detailed still displays it.
3. Open **Pass Checks** from a character with Checks. Search by part of a recipient's name. Try a name with an accent, a name with no matches and a recipient who already has Checks. Confirm that the available match can receive Checks and that both balances and chat update.
4. Repeat in Free Play with Turn Manager off. Try the arrow on a Character controlled only by the GM and on that Character's token. Confirm that an NPC cannot give or receive Checks.
5. Check the recipient search in Mouse Guard 1E and Mouse Guard 2E. In Legacy Mixed, optionally verify the QA.15 map marker size and visibility controls.
