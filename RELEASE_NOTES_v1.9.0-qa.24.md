# Realm Guard / Torchbearer v1.9.0-qa.24 — Final QA Cleanup

Focused follow-up to qa.23 based on live playtest feedback.

## Recruitment — Service & Specialty
- Service allocation counter updates immediately while points are entered.
- No Continue -> Back round-trip is needed to see the current total.
- Service allocation and Specialty selection synchronize live with wizard state.
- Counter visually distinguishes under, exact and over allocation.
- Existing Continue validation remains authoritative.

## Character — Wises / Traits
- Edit and delete glyphs on dark action buttons use a light parchment/gold foreground.
- Hover/focus contrast is strengthened.

## Item sheets
- Description textareas now use the same parchment writing-field language as the Name field:
  - light themed paper background
  - dark brown text
  - brown/gold border
  - dark caret
  - themed focus state
- Applies consistently to Wise, Trait, Gear, Condition, Token of Power and Talent descriptions.

## Scope
No rules changes.
No Actor/Item schema changes.
No M8 Social Network implementation.
No Relationship NPC creation.
No Quick NPC Library work.
